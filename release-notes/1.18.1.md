## 1.18.1

### Cleanup after 1.18.0
- Removes standalone duplicate Pilot Tools for checklists, VATSIM, ATC history and flight logging. These capabilities stay in their existing Flight Hub, ATC/Briefing and Flight Tracking modules.
- Renames the existing Flight Hub text area from **Scratchpad** to **Flight Notes** so it is no longer confused with the new drawing scratchpad.
- Replaces the 1.18.0 Scratchpad form with a real freehand scratchpad designed for mouse, touch and pen input.

### Real Scratchpad
- Adds pressure-aware pointer drawing with Pen, Marker and Eraser tools.
- Adds Undo, Redo, Clear, three line widths and Paper/Grid modes.
- Stores strokes locally and restores them after reloads.
- Adds an optional CRAFT quick-reference drawer without turning the drawing surface into a form.
- Adds PNG export for the current scratchpad page.

### Sim Session
- Keeps Sim Session as a separate app because it is genuinely new rather than a duplicate of an existing Flight Deck module.
- Existing internal shortcuts and guarded URI launch slots remain available.

### Performance
- Removes the duplicate 1.18 background flight-log/fuel-monitor/VATSIM refresh logic from the default UI path.
- The scratchpad does not add simulator polling and only redraws while visible or while drawing.

> Flight simulation use only — not for real-world navigation.
