## 1.20.4 — Complete SimBrief OFP & Cockpit UI

- Reworks the overall Flight Deck EFB visual system toward a cleaner airline-style cockpit workspace in both **Dark Mode and Light Mode**.
- Adds a persistent desktop cockpit navigation rail for **Home, Flight, OFP & Docs, Taxi, COM, Live Map, Apps and Settings**.
- Upgrades the SimBrief fetcher to the recommended **JSON v2** response format.
- Imports the actual SimBrief **`text.plan_html` Operational Flight Plan** instead of showing only the Flight Deck summary fields.
- Adds a safe, on-demand **complete OFP endpoint** so large briefing content is not broadcast with every simulator state update.
- Fixes SimBrief PDF link handling when the API returns a relative PDF filename plus a flight-plan directory.
- Keeps the generated SimBrief OFP layout intact inside a scrollable monospaced document workspace, with a plain-text fallback.
- Adds a dedicated **General** summary next to the original **Operational Flight Plan**, instead of conflating both views.
- Exposes available SimBrief NOTAM briefing text in the Documents workspace.
- Adds an OFP command bar with **Import SimBrief, Open OFP PDF, Import Documents, Label and Sync**.
- Imported local briefing files can now be renamed and re-labeled after import while remaining stored locally per flight.
- Keeps pen, highlighter, text note, eraser, undo/redo and color annotations available over the OFP/document workspace.
- Tightens the global visual hierarchy, card geometry, app launcher density, top flight strip and cockpit navigation for a more consistent EFB experience.
- Removes the old Flight Phase card from the Home dashboard so the main page prioritizes flight status and applications.
- Refreshes offline/PWA asset versioning for the new cockpit shell and complete OFP workspace.

> Flight simulation use only — not for real-world navigation.
