## 1.7.13 — Home Overlay Activation Fix

- Fixes the 1.7.12 packaging issue that left the old Home layout visible even though the new flight-overlay files were included in the installer.
- The release build now injects and version-busts the Home overlay CSS/JS explicitly before packaging, so stale 1.7.11 browser/service-worker assets cannot keep the old layout active.
- Bumps the application shell, module imports and service-worker cache to the current release version automatically during every Windows build.
- Home now activates the intended compact flight overlay with route progress, remaining distance, ETA, flight number, airport, runway, gate, altitude, IAS/GS and active/standby COM frequencies.
- UTC and local time are displayed together, the old Home flight-phase card is suppressed, and COM / Taxi / Live Map shortcuts are available from the flight summary.
