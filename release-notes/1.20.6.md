## 1.20.6 — Unified EFB UX

- Reworks the primary cockpit navigation into one stable set: **Home, Flight, Briefing, Taxi, COM, Live Map, Files and Settings**.
- Removes the duplicate **Apps** destination from the persistent navigation and keeps Home as the central flight/dashboard entry point.
- Adds a persistent global **UTC / Local Time** display alongside the existing flight context.
- Replaces the visible Flight Phase control workflow on the Flight page with a compact operational flight panel showing **route, progress, remaining distance/time, ETA, airport, runway, gate, speed, altitude, next waypoint and COM active/standby**.
- Keeps automatic flight-phase intelligence available in the background while removing manual/automatic phase controls from the primary pilot workflow.
- Integrates **Briefing / OFP** visually into the common Flight Deck shell instead of presenting it as a separate branded application window.
- Renames the pilot-facing Documents entry to **Briefing** while retaining the full SimBrief OFP, weather, NOTAM, PDF and annotation workflow.
- Integrates **Files** into the same global shell and removes its duplicate brand/theme/close chrome.
- Restricts Files to the dedicated **My EFB** application storage. The Files app no longer exposes Desktop, Downloads, the Windows home folder or PC drives.
- Creates managed EFB folders for **Briefings, Flight Plans, Documents, Imports, Exports and Screenshots**.
- Keeps Windows read/write access only inside My EFB; paired devices remain read-only inside the same app storage boundary.
- Adds a responsive **tablet/mobile bottom navigation** so primary navigation no longer disappears below 1100 px.
- Consolidates the active UI color/surface/spacing system across the core shell, Briefing and Files for more consistent **Dark and Light Mode** rendering.
- Increases secondary text and touch targets throughout the refreshed surfaces for better cockpit/tablet readability.
- Normalizes common status-chip styling and hides unavailable Charts from the primary application grid.

> Flight simulation use only — not for real-world navigation.
