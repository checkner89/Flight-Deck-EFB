## 1.7.19

### Traffic, maps and performance
- Filters generic Asobo `PassiveAircraft` placeholders such as `AS-GEN` from Live Traffic while retaining real injected simulator traffic.
- Fixes **ARRIVING** classification for descending traffic even when the basic SimConnect reader reports a synthesized `enroute` state.
- Reduces traffic discovery frequency, request fan-out and repeated state broadcasts to lower CPU and memory load.
- Refreshes live tracking from the shared simulator state so ownship and traffic remain visible on the Live Map.
- Shows moving ground traffic directly on the Taxi Map.
- Adds distinct Taxi, Parking, Arriving and Enroute status icons and colors.

### Aircraft and COM
- Reads the own-aircraft ATC airline and flight number and derives the real callsign instead of displaying the Fenix aircraft title as identity.
- Prevents aircraft manufacturer/model text such as `Airbus` from being treated as an airline/logo source.
- Applies COM active/standby, swap, RX and TX changes optimistically in the EFB and then reconciles them with the next simulator readback.

### Taxi planning
- Makes aircraft-to-taxiway snapping more tolerant of scenery/OSM geometry offsets while keeping distance safeguards.
- Avoids offering the live aircraft position as a departure start when a different airport is being planned.
- Improves automatic taxi-map refresh and moving-traffic awareness.

### GSX and Native EFB
- Adds Windows-host auto-discovery for the GSX profile directory, GSX handler library and MSFS Community folder; manual folder selection remains available as fallback.
- Expands Native EFB Builder auto-detection across environment variables, standard SDK locations, user folders, `where.exe`, UserCfg.opt and Community environment overrides.

### Interface
- Extends Focus Mode across the complete app with a global toolbar control and compact, distraction-reduced module layouts.
- Reworks the System settings layout into a clearer system-health and Native EFB Builder arrangement.

> Flight simulation use only — not for real-world navigation.
