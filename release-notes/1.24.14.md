# FLYXORA 1.24.14 — Retired News Source Cleanup

This maintenance release removes the retired News implementation from the repository source tree and hardens the Windows release path around the current FLYXORA runtime.

## Changes

- Removed the retired News JavaScript, stylesheet and backend service from the repository instead of carrying them as dead release-time cleanup targets.
- Kept the established 1.24.13 runtime behavior intact: no News UI/API/runtime remains and closing the main Windows window exits FLYXORA completely.
- Made the 1.24.14 release preparation repeat-safe so npm prepare, airport-data generation and installer builds no longer replay the full historical release chain after the current version is already materialized.
- Updated legacy installer and update-persistence regression checks for the current 1.24.14 FLYXORA release contract.
- Rebuilt and validated the Windows installer, packaged renderer and GitHub updater metadata, including `latest.yml`.
