## 1.20.7 — Flight Deck formatted SimBrief briefing

- Aligns the persistent left cockpit rail below the application toolbar instead of letting it intrude into the upper UI.
- Keeps the rail close to the top flight bar on Home, where no application toolbar is shown.
- Reworks the default SimBrief **OFP** into the native Flight Deck visual language instead of presenting the raw SimBrief document as the primary view.
- Adds a structured Flight Deck OFP hero with callsign, aircraft, route, distance and import metadata.
- Adds native Flight Deck sections for cruise data, cost index, EET, block time, SID and STAR.
- Adds structured ATC route, UTC OUT/OFF/ON/IN times, dispatch fuel and aircraft weight cards.
- Adds a scrollable navlog table with fix, airway, planned altitude, speed, distance and waypoint type.
- Adds departure, destination and alternate weather cards with runway, METAR and TAF.
- Makes imported SimBrief NOTAM text available inside the formatted OFP as an expandable briefing section.
- Keeps **Original OFP** as a separate document for the unmodified SimBrief HTML dispatch plan.
- Keeps the original **OFP PDF** available alongside the Flight Deck formatted presentation.
- Preserves Light/Dark Mode and the existing annotation/document workflow.

> Flight simulation use only — not for real-world navigation.
