## 1.18.0

### Pilot tools / Operations Suite
- Adds a persistent **Scratchpad** with CRAFT clearance fields and one-click autofill from the current flight, COM1 and transponder state.
- Adds **Smart Checklists** for Preflight, Before Start, Before Taxi, Before Takeoff, After Landing and Shutdown. Simulator-backed items are checked automatically while manual items remain stored per flight.
- Adds **Flight Documents** with an operational flight summary, OFP review/sign-off, JSON export and a post-flight summary.
- Adds an inferred **Fuel Receipt** that tracks on-ground fuel delivery from SimConnect and marks the source clearly when GSX does not expose an authoritative delivery record.
- Adds a persistent **Flight Log** with automatic off-block, takeoff, landing and on-block detection plus recent-flight history and JSON export.
- Adds an **ATC history** inside Flight Log that records exposed SayIntentions/ATC messages and clearance changes without polling the simulator again.

### VATSIM
- Adds an on-demand **VATSIM** application using the public VATSIM data feed.
- Shows relevant controllers for the active origin/current/destination airport and nearby VATSIM traffic within 120 NM of the simulator aircraft.
- Controller frequencies can be staged directly to **COM1 standby** using the existing COM controls and simulator readback.
- VATSIM refresh is limited to once per minute and only while the VATSIM tool is open to keep CPU/network load low.

### Sim Session / launcher
- Adds a **Sim Session** app with shortcuts into Taxi, COM, Live Map, ATC, Ground and Settings plus the configured Fenix Remote EFB.
- Adds guarded custom URI launch slots for registered Windows/Steam/tool-specific URI handlers. Unsafe `javascript:`, `data:` and `file:` schemes are blocked.

### UX and performance
- Adds six new app tiles to the Flight Deck launcher without expanding the main state-engine polling loop.
- The Operations Suite listens to the already shared `flightdeckstate` event instead of introducing additional SimConnect polling.
- Supports the global Flight Deck Focus Mode and responsive tablet layouts.
- Local notes, checklist progress, OFP reviews and logbook entries remain on the device in browser storage.
- Release validation covers Operations Suite syntax and asset wiring alongside the existing traffic, GSX and Native EFB regression checks.

> Flight simulation use only — not for real-world navigation.
