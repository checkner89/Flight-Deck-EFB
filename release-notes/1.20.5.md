## 1.20.5 — Complete File Browser

- Adds a new **Files** application to Flight Deck EFB with its own launcher tile and cockpit-rail shortcut.
- Adds a full local Windows file browser with **Back, Forward, Up, Refresh, editable path bar and recursive search**.
- Adds Quick Access for **Home, Desktop, Documents, Downloads, Pictures, Videos, Music and Flight Deck Data** plus detected Windows drives.
- Adds **list and grid views**, sortable Name / Modified / Type / Size columns and an optional hidden-files view.
- Adds multi-selection, Shift/Ctrl selection, keyboard navigation, **F2 rename**, **Delete**, **Ctrl+F**, Alt+Left/Right and context-menu actions.
- Adds file management for **new folders, new files, rename, copy, move and permanent delete**.
- Adds local file **upload** with drag & drop and explicit overwrite handling, supporting files up to 2 GB.
- Adds file **download** with HTTP range support for large files and media seeking.
- Adds built-in preview for **PDF, images, text/code, audio and video** plus a metadata panel.
- Adds direct editing and saving of text files up to 8 MB from the preview pane.
- Adds persistent **Favorites** and remembers view, sort and hidden-file preferences locally.
- Uses a security boundary: the Windows host has full read/write access; paired tablets and browsers are **read-only** and limited to the user's Quick Access roots.
- Adds canonical-path checks so linked/junction paths cannot escape the remote read-only boundary.
- Protects drive roots and Quick Access root folders from deletion.
- Adds responsive Light/Dark Mode styling for desktop, tablet and smaller displays.

> Flight simulation use only — not for real-world navigation.
