## 1.7.15 — ATC Center Layout

- Fixed the broken **SayIntentions SI controls** card that could collapse into a single narrow grid column on the ATC Center page.
- The SI controls now occupy the intended **seven-column desktop area** beside the manual-clearance card, creating a balanced second row instead of a detached card below the page.
- The **BeyondATC compatibility notice** stays below both clearance controls so the information hierarchy remains consistent.
- SI controls are now explicitly assigned to the **Clearance** tab and no longer remain visible when switching to **Messages** or **VATSIM / IVAO**.
- Reworked the SI session card spacing, pause/resume block, message channel selector, text area, send action and status feedback for clearer alignment and easier use.
- Added dedicated responsive behavior for medium windows, tablets and phones, including six-column balancing and full-width stacking at smaller breakpoints.
- Added explicit **light-theme** styling for SI control inputs, selectors and text areas to preserve contrast and readability.
- Added permanent **ATC Center regression checks** for grid placement, tab ownership, compatibility-note order, responsive breakpoints, light mode and delayed SI-card injection.
- Release notes and generated changelog entries are now checked to ensure every change item uses **bullet points**.
- Pre-release CI passed the ATC and COM regression checks, local host smoke test, Windows installer build, packaged-app startup smoke test and updater-asset verification before publication.
