## 1.20.3 — SimBrief OFP & Documents Workspace

- Adds a dedicated **OFP & Documents** cockpit workspace with a modern EFB layout and direct access from Home and Flight.
- Deepens **SimBrief integration** with structured flight-plan sections for General, ATC Plan, Fuel, Flight Times, airports, alternates, METAR/TAF and the original SimBrief OFP PDF inside Flight Deck EFB.
- Adds local import for **PDF, PNG/JPG/WebP and TXT** briefing documents, including multi-file import and per-flight categorization.
- Adds persistent per-flight **document annotations** with pan/scroll, pen, highlighter, text notes, eraser, undo/redo and multiple colors.
- Adds a persistent flight strip with route, flight number, progress, remaining distance, ETA, UTC/local time, runway and quick operational context.
- Adds live side-panel context for SimConnect, altitude, speed, COM active/standby, destination runway and destination weather, plus quick jumps to **COM, Taxi and Live Map**.
- Supports the complete workspace in both **Light and Dark Mode** using the existing Flight Deck theme control.
- Adds a guarded local **SimBrief document proxy** so the current OFP PDF can be displayed inside the paired EFB without exposing connector credentials.
- Keeps imported user documents and annotation data local to the device/browser storage.
- Bumps the offline application cache for the new document workspace so existing installations receive the new assets cleanly after update.

> Flight simulation use only — not for real-world navigation.
