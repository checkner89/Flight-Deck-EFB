Microsoft Flight Simulator / SimConnect / MSFS 2024 EFB SDK
------------------------------------------------------------
Flight Deck EFB optionally connects to Microsoft Flight Simulator through SimConnect and can build a native MSFS 2024 EFB package using the SDK/template already installed by the user.

Microsoft/Asobo SDK, template and simulator files are not redistributed by Flight Deck EFB and remain subject to Microsoft/Asobo terms.

SayIntentions.AI
----------------
Optional active-flight/SAPI compatibility. No SayIntentions account credential or API key is distributed with Flight Deck EFB. Living World traffic data available to Flight Deck is limited to information exposed through documented/local simulator interfaces.

BeyondATC
---------
Optional local read-only log compatibility. Flight Deck EFB does not distribute BeyondATC code or assets.

SimBrief / Navigraph
--------------------
Flight Deck EFB can use the SimBrief latest-OFP endpoint with a user-supplied Pilot ID/username. SimBrief/Navigraph terms apply. Standalone Navigraph chart embedding remains disabled unless a separately approved integration is available.

AviationWeather.gov
-------------------
Flight Deck EFB can request METAR/TAF data from AviationWeather.gov. Provider terms and operational disclaimers apply.

VATSIM / IVAO
-------------
Optional public live-network data can be requested when selected by the user. Network API, data and usage policies apply.

Little Navmap
-------------
Optional local WebAPI compatibility. Flight Deck EFB does not bundle Little Navmap code or databases.

Fenix Simulations
-----------------
Compatibility uses the official local Fenix Remote EFB/Web MCDU and MSFS Input Events exposed by the user's installed/running aircraft. Flight Deck EFB does not bundle a private or unofficial Fenix variable catalog.

PMDG
----
Compatibility can discover SDK header/options files already installed with the user's PMDG product and derive available event identifiers at runtime. Flight Deck EFB does not bundle, copy or redistribute PMDG SDK source/header content.

FSDreamTeam / GSX
-----------------
Compatibility uses local installation/process detection and documented GSX simulator variables. Flight Deck EFB does not bundle GSX code/assets and does not emulate a general remote GSX service API.
