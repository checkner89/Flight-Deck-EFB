4. LOCAL NETWORK AND CONNECTOR ACCESS

Flight Deck EFB runs a local Windows host to communicate with Microsoft Flight Simulator and optional local integrations. If LAN sharing is enabled, paired devices on the same trusted private network can access a sanitized EFB interface.

Do not expose the Flight Deck EFB local host directly to the public internet. Use LAN sharing only on networks and devices you trust.

Optional internet requests can be made to selected providers such as SimBrief, AviationWeather.gov, VATSIM, IVAO, OpenStreetMap/Overpass and GitHub Releases. Those providers process requests under their own policies.

5. LOCAL DATA AND PRIVACY

Flight Deck EFB can store settings, paired-device tokens, airport caches, automation rules, flight recordings, optional SimBrief identifiers and other application state in the current Windows user's application-data folder.

Normal application updates preserve this local data. Uninstalling Flight Deck EFB does not automatically delete the application-data folder. This prevents an uninstall or reinstall from unexpectedly deleting user-created flight history and settings.

The complete data-flow description is provided in PRIVACY.md and inside the application.
