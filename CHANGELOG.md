# Flight Deck EFB changelog

## 1.2.0 — 24 August 2026

- Combined SayIntentions/BeyondATC, VATSIM, and IVAO into one ATC Center.
- Added an optional complete SayIntentions message-session view.
- Disabled the standalone Charts launcher until a compliant Navigraph product
  placement and developer approval are available.
- Added a header Light/Dark toggle, stronger light-theme contrast, consistent
  button sizing, larger operational text, and a compact no-horizontal-scroll
  setup assistant.
- Reworked Automations into a responsive, labeled two-column rule builder with
  safe test mode, one-shot transitions, cooldowns, and audit logging.
- Corrected phase recommendations so they never open removed or unavailable
  apps.
- Added installed-version and Squirrel update state to Settings. New Setup
  packages upgrade in place while preserving Local AppData.
- Added application copyright, MIT License, third-party/data attribution,
  trademark disclaimer, privacy/data-flow documentation, and the permanent
  simulation-only notice.
- Increased the local SayIntentions message buffer to 100 entries.
- Retained the Windows installer, browser-host fallback, tablet access,
  SimBrief persistence, COM controls, simulator Flightboard, GSX readiness,
  Fenix Remote EFB, taxi planning, flight tracking, and six UI languages.

Flight simulation use only — not for real-world navigation.
