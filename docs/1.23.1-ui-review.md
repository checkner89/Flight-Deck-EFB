# Flight Deck EFB 1.23.1 UI review

Patch scope after the 1.23.0 cockpit review:

- normalize Home application labels and remove duplicate-looking Briefing/Communication tiles
- use one restrained cockpit icon palette and larger app icons
- remove News from visible Home/module navigation while preserving internal implementation
- remove cross-module quick navigation that leaked Taxi/Ground actions into Briefing
- restrict Plan Taxi to the Taxi workspace
- hide the airport map while Taxi has no active route
- restore Live Traffic map interaction to aircraft-only markers, flight number/callsign on hover, and details on click
- stabilize Guided Briefing rendering so unrelated state ticks do not rebuild the active briefing panel
- expose imported SimBrief OFP NOTAM text to the Guided Briefing NOTAM section
- remove Gate Assignment / Gate-Stand from the visible departure briefing
- simplify Guided Briefing hierarchy and equal-weight card clutter
- keep the Taxi planner centered, viewport-bounded and free of horizontal clipping on desktop/tablet layouts
- responsive desktop/tablet adjustments
- validate the final 1.23.1 package through the Windows release chain before merge and publishing

The patch remains additive and is applied after the 1.23.0 release materialization. Existing simulator, recorder, GSX, route, traffic-source and integration data flows are not replaced.
